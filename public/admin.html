Linux desktop companion

Same-PC only · owner-session pairing · local approval for sharing and input

Not paired
◇
Owner-session authorized · loopback only.

Start the companion manually with npm run companion, then pair with one click while signed in to the Nightjar owner console. No pairing code is used; the owner session and CSRF protection authorize a short-lived, one-use pairing ticket. The active pairing is revalidated against that signed-in owner session every 15 seconds and ends if its session becomes invalid. Screen sharing and mouse/keyboard input still require separate approval in the companion terminal. This does not enable system RDP, change firewall rules, or accept shell commands.

The companion has not been paired.

Click the screen to send a pointer click. Keyboard shortcuts and system keys are restricted. Sharing ends after one minute without an owner-console heartbeat.
